# Կաղապարային vs Բնական Հայերեն (Examples & Comparisons)

Այս բաժնում ներկայացված են AI մոդելների առավել տարածված կաղապարային ձևակերպումները, դրանց բնական այլընտրանքները և լեզվական/տեխնիկական պատճառաբանությունը։

---

| ❌ Կաղապարային / Ոչ ճշգրիտ (AI Default) | ✔️ Բնական Հայերեն | 💡 Ինչո՞ւ է երկրորդը նախընտրելի (Պատճառաբանություն) |
| :--- | :--- | :--- |
| **Հնացած շրջանակ** (երբ խոսքը framework-ի մասին է) | **Հնացած ծրագրային շրջանակ** (framework) կամ **ծրագրային հարթակ** (platform) | «Շրջանակ» բառն առանց տեխնիկական հստակեցման հայերենում նշանակում է ֆիզիկական շրջանակ կամ թեմայի շրջանակ (scope): Framework-ի համար ճշգրիտ է `ծրագրային շրջանակ`, իսկ platform-ի համար՝ `ծրագրային հարթակ`: |
| **Տվյալները հանդիսանում են կարևոր** | **Տվյալները կարևոր են** | Ռուսերեն «является» կապի ավելորդ մեխանիկական ներմուծում։ Հայերենում պարզ էական բայը («են») ավելի բնական է (թեև առանձին պաշտոնական կառույցներում «հանդիսանալ» բայն ունի իր տեղը)։ |
| **Մեր կողմից առաջարկվում է իրականացնել** | **Անհրաժեշտ է իրականացնել / Ենթակա է իրականացման** | Պաշտոնական-աուդիտորական եզրակացության մեջ անձնական դերանուններով («մեր կողմից») ծանրաբեռնվածությունը խախտում է օբյեկտիվ ոճը։ |
| **Անընդհատ կրկնվող «առաջարկվում է...»** | **Նպատակահարմար է... / Ենթակա է...** | Թեև «առաջարկվում է» ձևը քերականորեն սխալ չէ, անընդհատ կրավորական կառույցների շարանը տեքստը դարձնում է ծանրաշարժ։ |
| **Սերվերը կապ է հաստատել C2-ի հետ** | **Նախատեսված է եղել կապ հաստատելու համար** | Եթե չկան ցանցային հաստատված լոգեր, կոդում առկա հասցեն փաստացի միացման ապացույց չէ (փաստի և հնարավորության տարբերակում)։ |
| **Կիբերհարձակում** | **Կիբեռհարձակում** | ՀՀ օրենսդրությամբ («Կիբեռանվտանգության մասին» ՀՕ-442-Ն օրենք) սահմանված է «կիբեռ-» տարբերակը (թավ «ռ»-ով)։ |
| **Կիբեռհարձակում (երբ խոսքը միջադեպի մասին է)** | **Կիբեռմիջադեպ** | ՀՀ Օրենք ՀՕ-442-Ն (հոդվ. 3)՝ «կիբեռմիջադեպը» համակարգում տեղի ունեցող ցանկացած գործողություն կամ միջամտություն է, որն անխուսափելիորեն վտանգում է կամ բացասաբար է անդրադառնում կիբեռանվտանգության վրա։ |
| **Կիբեռմիջադեպ (երբ խոսքը հարձակման մասին է)** | **Կիբեռհարձակում** | ՀՀ Օրենք ՀՕ-442-Ն (հոդվ. 3)՝ «կիբեռհարձակումը» համակարգի նկատմամբ դիտավորությամբ կամ ուղղորդմամբ կատարվող գործողությունների ամբողջությունն է՝ բնականոն գործունեությունը խաթարելու, չարտոնված մուտք ստանալու կամ տվյալների վրա ազդելու նպատակով։ |
| **Տեղի է ունեցել իրականում** | **Իրականում / Փաստացի տեղի է ունեցել** | Բառացի մեխանիկական թարգմանություն անգլերեն «what actually happened»-ից։ |
| **Զագրուզկա անել / ֆայլը քաշել** | **Ֆայլը վերբեռնել (upload) / ներբեռնել (download)** | Ժարգոնի կամ օտար բառերի փոխարինում հայերեն հաստատված պաշտոնական եզրույթներով։ |
