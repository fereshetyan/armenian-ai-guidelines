# Տեղեկանք Տառատեսակների Իրավական Կարգավիճակի Մասին (Fonts Legal Notice)

Այս թղթապանակում ներկայացված են Հայաստանի Հանրապետության պաշտոնական գրագրության համար հաստատված համակարգչային տառատեսակները։

---

### 1. Հեղինակային Իրավունք (Authorship & Intellectual Property)
- **Հեղինակ՝** Էդիկ Ղաբուզյան (Edik Ghabuzyan)։
- **Արտադրող / Իրավատեր՝** Հայաստանի ազգային գրապալատ (Armenian National Book Chamber), Copyright (c) 2007:
- **Ապրանքային նշաններ՝** «GHEA Grapalat» և «GHEA Mariam» տառատեսակների անվանումները հանդիսանում են հեղինակի գրանցված նշանները։

---

### 2. Պետական Կարգավիճակ (State Adoption)
Համաձայն **ՀՀ Կառավարության 2010 թվականի սեպտեմբերի 24-ի N 1259-Ն որոշման** («Հայաստանի Հանրապետության պետական պաշտոնական փաստաթղթաշրջանառությունում պարտադիր կիրառման հայկական համակարգչային տառատեսակները հաստատելու մասին»)՝
- «Գրապալատ» (GHEA Grapalat) և «Մարիամ» (GHEA Mariam) տառատեսակները հաստատվել են որպես պետական պաշտոնական փաստաթղթաշրջանառությունում պարտադիր կիրառման ենթակա համակարգչային տառատեսակներ։
- Որոշմամբ սահմանված է, որ տառատեսակները հանդիսանում են ՀՀ պետական սեփականություն և անվճար ու անարգել կարող են օգտագործվել ֆիզիկական և իրավաբանական անձանց կողմից էլեկտրոնային տեղեկատվական ու հաղորդակցման համակարգերում։

---

### 3. Պաշտոնական Աղբյուրներ (Official Sources & Download)
Պետական տառատեսակների պաշտոնական բնօրինակները հասանելի են ՀՀ պետական պորտալներում․
- ՀՀ Բարձր տեխնոլոգիական արդյունաբերության նախարարություն (HTI / Gov.am)
- [ՀՀ Իրավական տեղեկատվական համակարգ (ARLIS - Որոշում N 1259-Ն)](https://www.arlis.am/DocumentView.aspx?docid=61219)

Սույն պահոցում տեղադրված `.ttf` ֆայլերը ներկայացված են զուտ ավտոմատացված գործիքների և AI փաստաթղթերի գեներացման տեխնիկական փորձարկումների հարմարավետության համար։
